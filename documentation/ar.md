# Canadian C-Spine Rule

[الشروط والمصادر والأذونات](https://elucenia.org/ar/tools/canadian-c-spine-rule)

## المدخلات والوحدات

### معيار استبعاد: عمر \< ١٦ سنة، Glasgow \< ١٥، علامات حيوية غير طبيعية، إصابة منذ أكثر من ٤٨ h، إصابة نافذة، شلل حاد، مرض فقري معروف/جراحة رقبة سابقة، عودة لتقييم الإصابة نفسها أو حمل

`excl`

### خطر مرتفع: العمر ≥ ٦٥ سنة

`idade65`

### خطر مرتفع: آلية خطرة (سقوط ≥ ٠٫٩ m أو ٥ درجات، حمل محوري على الرأس، تصادم سريع، انقلاب أو قذف، مركبة ترفيهية بمحرك، تصادم دراجة)

`mecanismo`

### خطر مرتفع: تنميل بالأطراف

`parestesia`

### خطر منخفض: تصادم خلفي بسيط (دون دفع المركبة للاتجاه المعاكس أو اصطدام حافلة/شاحنة كبيرة أو انقلاب أو تصادم سريع)

`colisao`

### خطر منخفض: جالس في غرفة الطوارئ

`sentado`

### خطر منخفض: مشى في وقت ما بعد الإصابة

`deambulou`

### خطر منخفض: ألم رقبة متأخر البدء

`tardia`

### خطر منخفض: لا ألم بجس الخط الناصف الرقبي

`semdor`

### هل يستطيع تدوير الرقبة بنشاط ٤٥° يمينًا ويسارًا؟

`rot`

اختياري

- `0` — لا
- `1` — نعم
- `na` — لم يُختبر بعد

### إصابة كليلة منذ ≤ ٤٨ h؛ عمر ≥ ١٦ سنة، Glasgow ١٥، علامات حيوية طبيعية، وتأكيد الإدراج بألم الرقبة أو إصابة فوق الترقوة + عدم المشي + آلية خطرة؟

`contexto`

- `0` — لا
- `1` — نعم
