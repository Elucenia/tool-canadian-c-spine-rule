# Source and material scope: canadian-c-spine-rule

## Distribution scope

own-method-code-published-mathematical-or-boolean-facts

Own arithmetic/boolean method implementation, observed inputs, short authorial clinical descriptions and numerical constants; no source article, diagram, poster, data bank, service code or third-party application is bundled.

## Source-specific finding

The current payload implements the scientific method in own code. A publication/site copyright is not transferred to the numerical facts or method itself, and its accessibility is not treated as permission to copy protected article/instrument expression.

## Required scope and remaining issue

Preserve scientific citation, edition and the Apache/MIT component notices. Keep authorial translations identified as unofficial and technical evidence distinguished from clinical validation.

No specific third-party permission requirement is evidenced for this own-code scope. Reproducing source papers, posters, protected forms or official translations would need separate review.
